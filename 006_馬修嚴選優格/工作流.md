# 006 馬修嚴選優格 — 迷你人物坐罐頂 工作流

產品：馬修嚴選 Pro+ 乳蛋白優格分享號（960g）
概念：一隻手把優格托起，綠蓋上有四位迷你職業人物（兩位上班族＋兩位運動感，20–40 歲）。純白背景。

## 現行版本（v2 重寫，2026-06-12）

執行於 Magnific Space「**006 馬修嚴選優格 合成 v2**」。第一版工作流（角色先生成定稿、再多圖合成）迭代多輪後節點混亂，且參考圖與 prompt 描述容易打架導致人物漂移，重寫為**單一參考圖＋人物純文字描述**：

```
圖1 產品照（優格罐）──┬──> 合成A：手指繞後
                      └──> 合成B：正面盛托
```

- **人物不再上傳參考圖**，直接在 prompt 描述四個人設（上班族女／上班族男／運動男奔跑／運動女），由左至右排好，三坐一跑
- 兩個生成節點只差「手勢」段落：**A＝手指繞後**（正面最乾淨）、**B＝正面盛托**（捧起獻上感，會碰罐身下緣）
- 共同規格：Nano Banana 2、3:4、4K；產品標籤鎖死不可變形；背景純白 #FFFFFF 寫死（防參考圖灰底污染）；真實人手要求（皮膚紋理、禁蠟感/CG感/多指/戒指）；罐子中段偏下、蓋上留罐身一半高度空間給人物
- 完整 prompt 以 Space 節點內容為準

## 翻車教訓（v1 累積）

1. **prompt 裡的人物描述若與參考圖內容不符，人物會漂移**（角色重複、消失）。要嘛全參考圖、要嘛全文字，不要混。
2. 手的「支撐感」寫法：手從下方、手掌攤平托罐底、手指繞後不遮標籤；力量感＝「手背筋脈微浮、掌根緊壓罐底」；太誇張就刪筋脈句。
3. 手臂佔比要控制：「只露手掌與手腕，不露前臂與手肘」＋「罐子中段偏下」才能把空間讓給人物。
4. 板上的圖片節點被換掉後，prompt 內的 @ 節點引用會變成孤兒，每次換圖要重新確認引用。
5. 運動服極易生出品牌 logo（Nike 勾勾），必寫 plain unbranded / no logos。
6. 生成的手容易蠟感＋自己長戒指，寫實要求與禁飾品要常駐。
