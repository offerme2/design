# CIPU 參考圖工作流

新素材的接力流程：你把參考圖丟進這個資料夾（或丟 Drive 連結到對話），我接手出 prompt、生圖、壓字、輸出上線檔。

## 怎麼上傳

擇一即可：

1. **GitHub 網頁上傳**：直接把圖拖進這個 `CIPU/參考圖/` 資料夾（建議開子資料夾，命名 `日期_主題/`，例：`0612_巨大包場景/`）。
2. **Google Drive**:丟分享連結到對話，我自己讀清單。
3. **生成工具內**：若是 Nano Banana Pro / Magnific 等工具的產出，貼截圖＋告訴我 Space 名稱（例：換包包）。

## 我接手後的流程

```
參考圖 → 視覺方向判讀 → 英文生成 prompt（可直接貼生圖工具）
       → 你生圖 / 我用 MCP 生圖 → 定稿圖回傳
       → 套版壓字（CIPU/tools/ 腳本）→ 輸出 1080x1080 + 1080x1920
       → 存 CIPU/素材輸出/，依命名規則進測試
```

## 命名規則（沿用測試計畫）

```
{系列}{編號}_{切角}_{色碼}_{尺寸}.png
例：ATT3_態度_巨大包_BK_1080x1080.png
```

## 已建立的版式

| 版式 | 適用 | 腳本 |
|------|------|------|
| B 系列：白底＋商品大圖＋單句標語 | 賣點測試 | `CIPU/tools/make_b_series.py` |
| ATT 系列:包體撐滿出血＋左上小字 | 態度／少字方向 | 同腳本邏輯（huge 版式） |
| AI 生成場景＋壓字 | 巨大包等情境圖 | 定稿後沿用 ATT 小字版式 |
