## 🖼️ 視覺元素慣性

### 背景風格
- **香檳金漸層光暈**:金色從上方或側面打光,營造奢華感(品牌招牌手法)
- **節慶氛圍**:母親節加入粉色康乃馨、緞帶
- **實驗室調性**:玻璃器皿、滴管、產品 D-cut,呈現專業精華液感(獎項稿常用)

### 裝飾元素
- **細金線分隔線(───)**:放在副標兩側,**就是一條乾淨的細直線**,不要捲花、星點、勾邊、花角等小裝飾(AI 生圖特別容易亂加,要明講「plain thin line」)
- **圓角矩形卡片**:價格/活動規則框 ——「米白半透明底 + 細金線邊」
- **橢圓膠囊標籤 / 圓形徽章**:金色邊框。膠囊用於「人氣加購價」「滿額折扣優惠」等;**現省獨立成行時用圓形徽章(金底或紅底)**,字級小於主價。
- **構圖保持開放、乾淨通透**:金線只當副標兩側或卡片的點綴;**整張圖不加四周外框**,邊緣留白讓版面透氣。

### 1920×800 橫式(官網 Banner)

## 🔘 CTA 按鈕慣性
- 形狀:**方正矩形,直角或極小圓角**,俐落專業。
- **尺寸 padding**:按鈕貼合文字,左右留白適中;高度約一行字加上下小留白即可,保持精緻。
- 底色:深咖啡 `#3D1E0E`
- 文字:白色襯線體
- 慣用文案:「首購免運再領 $100 立即下單 ▶▶」「立即搶購」「立即體驗」
- **結尾必加箭頭**:`▶▶` 或 `»`,給出下單導引的視覺暗示。

## 💰 價格資訊慣性

**價格要分主從**(主價一個焦點,現省當配角):

| 角色 | 怎麼做 |
|------|--------|
| **主價**(限時價/特價) | 紅色 `#C8102E` **大字襯線** —— 全圖價格焦點,只有它放大。 |
| **現省/現折** | 做成**小標籤**,字級**明顯小於主價**。兩種形式:① 接在主價旁/下方 → 膠囊或方標(金邊/米白底);② **獨立成行時 → 用圓形徽章(圓標)**,金底或紅底。 |

- 「現省」「現折」「滿額折後」文字:黑色襯線中文(或標籤/圓標內白字)
- `$` 符號:與數字同色同字型
- **千分位逗號必加**:`$3,580`、`$1,170`

> ✅ 一張圖只有「主價」能放大,現省永遠是配角小標籤,價格的主從才清楚。

## 🧴 三產品線視覺差異(維他命C / Stem Lift / 五重酸)

母品牌的**字型、香檳金、警示紅維持一致**;每條產品線只換**主色 + 輔色 + 氛圍**,從暖到冷各跳一階,做出區隔但仍是同一家。

| | **維他命C** | **Stem Lift** | **五重酸** |
|---|---|---|---|
| **氛圍** | 奢華煥膚 | 熟齡輕奢 | 清新藥妝 |
| **主色** | 深咖啡 `#3D1E0E`(母品牌色) | 米金 `#C9A876` | 深海軍藍 `#0A2A5E` |
| **輔色** | 香檳金 `#D4A857` + 米白 `#F5E6C8` | 柔光金 `#E8D9B8` + 奶白 | 冰川灰藍 `#A8C8DC` + 純白 |
| **客群** | 想抗老、淨白、亮 | 熟齡 40+,想拉提緊緻 | 毛孔/粉刺、想要絲滑底妝 |
| **三線共用(不要動)** | 主標游明朝 Demibold ・ 價格警示紅 `#C8102E` 襯線 ・ 內文思源黑體 ・ 深咖啡 CTA | | |

**怎麼判斷一張稿屬於哪條線**:看主色。暖咖啡=維他命C、米金=Stem Lift、深藍=五重酸。三條線放在一起時,**靠主色區分,靠字型與金/紅維持一家人**。各線主色彼此獨立,不互相借用,產品差異才看得出來。

## ✍️ 文案字數規則(直接套字數,不用另查)

各文字區塊的字數慣例如下(以實際交付稿歸納,可視版面微調):

| 區塊 | 字數慣例 | 範例 |
|------|----------|------|
| **檔期標** | 中文 **3–8 字**,放在 Logo 下方 | 「618 年中慶」「母親節極效煥膚緻禮」 |
| **主標 Headline** | **一行**(不堆兩排),常見 **8–10 字**,多為**兩段式 4+4 或 4+5**,中間用空格或 × 分隔;節慶/獎項用完整短句約 8–10 字 | 「角質煥新 × 極致拋光」「角質煥新 肌再生革命」「母親節極效煥膚緻禮」「日本美容大賞 134 冠王」 |
| **副標 Subtitle** | **一行**:產品名(英文)+ 中文功能訴求,中文約 **8–12 字**,可帶兩段(成分＋情境),左右加金線 ─── | 「高濃度純維他命C精華」「15種複合酸前導精華 角質代謝居家煥膚」 |
| **主價** | 「限時/特價 $X,XXX」 | 限時 $2,380 |
| **現省**(圓標) | 「現省 $X,XXX」,**約 4–5 字 + 金額** | 現省 $1,200 |
| **CTA** | **常是一整句促購**(優惠＋動作＋箭頭),約 **10–18 字**;短版才用「4 字動作＋箭頭」。結尾必加箭頭 | 「首購免運再領 $100 立即下單 »」「新品限時 9 折再送 C25 維他命 C 精華 ▶▶」「立即搶購 ▶▶」 |
| **亮點 callout** | 賣點小字,約 **4–8 字**,常配 ● 或獨立放在產品旁 | 「毛孔 明顯縮小」「淡化斑點、緊緻毛孔」 |

**寫文字時的順序**:檔期標 → 主標 → 副標 → 價格(主價大、現省圓標)→ CTA(4 字 + 箭頭)。

> ✅ 主標排一行(可兩段 4+4,中間空格或 ×),別堆成兩排;CTA 不必硬湊四字,真實稿多是一整句促購。字數抓「真實稿」的感覺,別被理論值綁死。

## 🤖 AI 生圖 Prompt 規範

原則:**視覺元素不要寫死,用參考圖定氛圍**。

- ✅ prompt 寫「請參考附圖的氛圍」+ 配色(依產品線主色)+ 版面結構
- ✅ 自己提供參考圖,把 prompt 當品牌規範、參考圖當靈感
- ✅ **線條/邊框要明講「乾淨」**:GPT 系生圖很愛在分隔線加捲花、星點、小裝飾——prompt 要寫「plain thin straight lines, no ornaments/flourishes」
- ✅ AI 算完後**一定人工確認**:配色有沒有偏、價格字是不是紅色襯線、Logo 比例與位置、CTA 箭頭在不在、**分隔線有沒有被加小裝飾**
