## 🖼️ 視覺元素慣性

### 背景風格
- **香檳金漸層光暈**:金色從上方或側面打光,營造奢華感(品牌招牌手法)
- **節慶氛圍**:母親節加入粉色康乃馨、緞帶
- **實驗室調性**:玻璃器皿、滴管、產品 D-cut,呈現專業精華液感(獎項稿常用)

### 裝飾元素
- **細金線分隔線(───)**:放在副標兩側
- **圓角矩形卡片**:價格/活動規則框 ——「米白半透明底 + 細金線邊」
- **橢圓膠囊標籤 / 圓形徽章**:金色邊框。膠囊用於「人氣加購價」「滿額折扣優惠」等;**現省獨立成行時用圓形徽章(金底或紅底)**,字級小於主價,別做成大紅字

## 🔘 CTA 按鈕慣性
- 形狀:**方正矩形,直角或極小圓角**(不要大圓角、不要膠囊藥丸形)
  - ⚠️ GPT/AI 生圖很愛把 CTA 做成大圓角藥丸狀 —— 那不是 Dermacept 的調性,要拉成方正
- **尺寸 padding**:按鈕貼合文字,**左右留白適中、不要過寬**;高度約一行字加上下小留白即可
  - ⚠️ 別做成橫跨整個版面、內部塞一堆空白的大色塊 —— padding 太多會顯得鬆、不俐落
- 底色:深咖啡 `#3D1E0E`
- 文字:白色襯線體
- 慣用文案:「首購免運再領 $100 立即下單 ▶▶」「立即搶購」「立即體驗」
- **結尾必加箭頭**:`▶▶` 或 `»`

## 💰 價格資訊慣性

**價格要分主從,不要兩個一樣大**(這是 AI 生圖最常犯的錯):

| 角色 | 怎麼做 |
|------|--------|
| **主價**(限時價/特價) | 紅色 `#C8102E` **大字襯線** —— 全圖價格焦點,只有它能放大 |
| **現省/現折** | 做成**小標籤**,字級**明顯小於主價**。兩種形式:① 接在主價旁/下方 → 膠囊或方標(金邊/米白底);② **獨立成行時 → 通常用圓形徽章(圓標)**,金底或紅底 |

- 「現省」「現折」「滿額折後」文字:黑色襯線中文(或標籤/圓標內白字)
- `$` 符號:與數字同色同字型
- **千分位逗號必加**:`$3,580`、`$1,170`

> ⚠️ 別把「現省 $X」做成跟「限時 $X」一樣大的兩行紅字 —— 那樣價格沒有主從,看起來像兩個價在打架。現省永遠是配角小標籤。

## 🚫 雷區清單(每接一次案都要回來補)

> ⚠️ 全文件最重要的段落。客戶/品牌過去明確不要的事,都記在這。
> 每個新對話開始時,優先掃這張表,自動轉成「絕對不要做」的硬規則。

| 雷區 | 為什麼 |
|------|--------|
| **粉色出現在非節慶檔期** | 粉嫩 `#F4D8D0` 只配母親節,平常用會掉檔次 |
| **粉紅絲帶感**(整體偏粉嫩柔焦) | 與高端奢華調性衝突 |
| **不實訴求**:百貨第一名、專櫃旅行組、皮膚科推薦 | **Dermacept 是純電商,沒百貨櫃** —— 寫了會誤導,設計部紅線 |
| **主標不用游明朝** | 失去品牌辨識度 |
| **價格用無襯線/非紅色** | 破壞「紅色襯線價格」的轉換慣性 |
| **CTA 結尾沒箭頭** | 少了下單導引的視覺暗示 |
| **CTA 用大圓角/膠囊藥丸形、或 padding 過寬** | AI 生圖常犯;Dermacept CTA 是方正、貼合文字的按鈕,不是橫跨版面的大色塊 |
| **現省做成跟主價一樣大的紅字** | 價格沒主從;現省應是小標籤,只有主價能放大 |
| **Logo 太小或貼邊** | 低於 15% 寬度、安全距離不足 |
| **螢光色/廉價促銷感** | 不符精華液高端調性 |

## 🧴 三產品線視覺差異(維他命C / Stem Lift / 五重酸)

母品牌的**字型、香檳金、警示紅維持一致**;每條產品線只換**主色 + 輔色 + 氛圍**,從暖到冷各跳一階,做出區隔但仍是同一家。

| | **維他命C** | **Stem Lift** | **五重酸** |
|---|---|---|---|
| **氛圍** | 奢華煥膚 | 熟齡輕奢 | 清新藥妝 |
| **主色** | 深咖啡 `#3D1E0E`(母品牌色) | 米金 `#C9A876` | 深海軍藍 `#0A2A5E` |
| **輔色** | 香檳金 `#D4A857` + 米白 `#F5E6C8` | 柔光金 `#E8D9B8` + 奶白 | 冰川灰藍 `#A8C8DC` + 純白 |
| **客群** | 想抗老、淨白、亮 | 熟齡 40+,想拉提緊緻 | 毛孔/粉刺、想要絲滑底妝 |
| **三線共用(不要動)** | 主標游明朝 Demibold ・ 價格警示紅 `#C8102E` 襯線 ・ 內文思源黑體 ・ 深咖啡 CTA | | |

**怎麼判斷一張稿屬於哪條線**:看主色。暖咖啡=維他命C、米金=Stem Lift、深藍=五重酸。三條線放在一起時,**靠主色區分,靠字型與金/紅維持一家人**。

> ⚠️ 別把三條線的主色混用(例:五重酸用了米金),會看不出產品差異。

## ✍️ 文案字數規則(直接套字數,不用另查)

各文字區塊的字數慣例如下(以實際交付稿歸納,可視版面微調):

| 區塊 | 字數慣例 | 範例 |
|------|----------|------|
| **檔期標** | 中文 **3–8 字**,放在 Logo 下方 | 「618 年中慶」「母親節極效煥膚緻禮」 |
| **主標 Headline** | 核心是 **4 字短句**,常**兩句堆疊(4字×2=8字)**;節慶可用較長整句約 8–10 字。最多 2 行 | 「熟齡緊緻 / 彈潤拉提」「極效煥膚 / 緻禮」 |
| **副標 Subtitle** | **一行**:產品名(英文)+ 中文功能訴求,中文約 **6–10 字**,左右加金線 ─── | 「Stem Lift 米金賦活精華」「高濃度純維他命 C 精華」 |
| **主價** | 「限時/特價 $X,XXX」 | 限時 $2,380 |
| **現省**(圓標) | 「現省 $X,XXX」,**約 4–5 字 + 金額** | 現省 $1,200 |
| **CTA** | **4 字動作** + 箭頭;若加優惠前綴,整句 ≤ 約 14 字 | 「立即搶購 ▶▶」「首購免運再領 $100 立即下單 ▶▶」 |

**寫文字時的順序**:檔期標 → 主標(先湊出 4 字短句)→ 副標 → 價格(主價大、現省圓標)→ CTA(4 字 + 箭頭)。

> ⚠️ 主標超過兩行、或一句塞太多字,版面會擠掉產品圖與留白,精品感就沒了。寧可拆成兩個 4 字短句堆疊。

## 🤖 AI 生圖 Prompt 規範

原則:**視覺元素不要寫死**。

- ❌ 不要在 prompt 硬塞「金光暈 + 緞帶康乃馨」這種固定元素
- ✅ 改成:「請參考附圖的氛圍」+ 配色(依產品線主色)+ 版面結構
- 自己提供參考圖,把 prompt 當品牌規範、參考圖當靈感
- AI 算完後**一定人工確認**:配色有沒有偏、價格字是不是紅色襯線、Logo 比例與位置、CTA 箭頭在不在
